# はじめに（Getting Started）

ftvrcm をインストールして、Fire TV Stick でタッチ操作を使えるようにするまでの手順を説明します。

## 前提条件

- Fire TV Stick（minSdk 28 / Android 9.0 以上）
- APK をサイドロードするための ADB 環境（PC）
- （推奨）Shizuku アプリ（`moe.shizuku.privileged.api`）

## 1. APK のインストール

### デバッグ APK（推奨：開発・評価用）

```bash
# Fire TV で ADB デバッグを有効化しておく（設定 → マイ Fire TV → 開発者オプション → ADB デバッグ）
adb connect <FIRE_TV_IP>:5555
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

APK のビルド方法は [APK をビルドしてインストールする](../how-to/build-and-install.md) を参照してください。

## 2. Shizuku と AccessibilityService の有効化

### 2.1 Shizuku の権限許可（推奨）

Shizuku を使うことで、0ms 遅延のタッチ注入・スワイプ・ネイティブ 2 本指ピンチ操作およびアプリ内からのアクセシビリティ有効化が利用できます。

1. Fire TV 上で Shizuku サービスを起動しておく（詳細は [Shizuku をセットアップする](../how-to/setup-shizuku.md) を参照）
2. **ftvrcm** の設定画面を開く
3. **Shizukuの設定** → **Shizukuを使用する（推奨）** が ON になっていることを確認する
4. **Shizukuの詳細設定** → **Shizuku権限の許可** を選択し、許可ダイアログで許可する

### 2.2 AccessibilityService の有効化

本アプリはアクセシビリティサービスとして動作します。インストール後に有効化が必要です。

- **Shizuku を使う場合（簡単）**：**Shizukuの詳細設定** → **アクセシビリティを有効化** を選択
- **設定 UI を使う場合**：Fire TV の **設定** → **ユーザーコントロール** → **アクセシビリティ**（または「ダウンロードしたサービス」）→ `ftvrcm` を **ON**

設定画面下部のステータスバーで「**アクセシビリティ: 動作中**」と表示されていれば準備完了です。

> ADB からも有効化できます。詳細は [AccessibilityService を有効化する](../how-to/enable-accessibility-service.md) を参照してください。

## 3. 基本操作

### 操作モードの切り替え

デフォルトでは **MENU キー長押し** で「無効（通常操作）」と「有効（タッチ操作）」を切り替えます。

- **無効（通常操作）**：リモコンが通常どおり動作（十字キーでフォーカス移動など）
- **有効（タッチ操作）**：画面上のカーソルを動かしてタップ・スクロール/スワイプ・ピンチズームを行う

### タッチ操作モードでの操作

| 操作 | デフォルトキー |
|------|-------------|
| カーソル移動 | 十字キー（上/下/左/右） |
| タップ / ロングタップ | 決定ボタン（短押し / 長押し） |
| 上下スクロール / スワイプ | CH+ / CH- |
| 左右スクロール / スワイプ | 巻き戻し（REW）/ 早送り（FF） |
| ズームイン（ピンチアウト） | 戻る（BACK） |
| ズームアウト（ピンチイン） | 再生 / 一時停止（MEDIA_PLAY_PAUSE） |
| リモコン操作パススルー切り替え | MENU（短押し） |

### 設定画面の開き方

Fire TV のホーム画面または「インストール済みアプリ」から **ftvrcm** を起動すると設定画面が開きます。

## 4. タッチ操作を確認する

設定画面 → **その他** → **タッチ操作テストを開く** から、タップ・スクロール・スワイプ・ズームが正しく動作するか確認できます。

詳細は [タッチ操作テストの使い方](../how-to/touch-test.md) を参照してください。
