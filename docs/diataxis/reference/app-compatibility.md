# アプリ・ゲーム動作確認一覧

Fire TV Stick 上で各アプリ・ゲームを操作した際の、**「リモコンのみ」「`ftvrcm`」「`ftvrcm+shizuku`」** ごとの使用可能レベルをまとめた一覧です。

- **レベル**：AI エージェントが `adb` 経由で実際に画面を動かして確認した評価です。
- **メモ**：AI エージェントによる検証時の所見（操作上の制限・必要な設定変更等）や、開発者による実機使用時の感想などを記載します。

---

## 使用可能レベルの定義

| レベル | 基準 | 「リモコンのみ」の典型例 | 「`ftvrcm` / `ftvrcm+shizuku`」の典型例 |
| :---: | :--- | :--- | :--- |
| **◎** | **快適**：主要な機能・導線がすべて意図通り反応し、詰まりなく一通りの利用 / プレイが完結できる | TV 対応 UI で、十字キー＋決定 / 戻るだけで全操作が可能 | カーソル＋タップ / スワイプ / 戻る等で違和感なく一通り操作できる |
| **○** | **実用可**：一通りの利用 / プレイは可能だが、一部に制約や手順の工夫（設定変更、パススルー切替等）が必要 | 大半は動くが、一部メニューにフォーカスが当たらない等 | 主要操作は通るが、キー干渉回避の設定変更や文字入力の工夫が必要 |
| **△** | **一部制限**：起動や一部画面の操作はできるが、肝心の機能・本編の進行が操作上の理由で困難 | トップ画面だけ押せるが、その先のボタンが押せず詰む | 単発タップは効くが、スクロール不可・マルチタッチ不可等で詰む |
| **✕** | **不可**：起動しない、または入力が一切受け付けられず操作不能 | カーソルもフォーカスも出ず何も選べない | タッチ注入自体が弾かれる／画面表示が崩れる |

---

## 表の見方

- **アプリver. / ゲームver.**：動作確認を行った対象アプリ・ゲーム側のバージョン（`versionName`）。
- **操作方法**：`リモコンのみ`（`ftvrcm` 無効）／`ftvrcm`（Shizuku 無効）／`ftvrcm+shizuku`（Shizuku 有効）。
- **ftvrcm ver.**：検証時の `ftvrcm` のバージョンまたは短縮コミットハッシュ（例: `v0.1.0 (c46d6fe)` / `c46d6fe`）。`リモコンのみ` の場合は `―`。
- **レベル**：上記「使用可能レベルの定義」に基づく評価記号。
- **メモ**：AI エージェントが検証時に確認した操作上の制限・必要な設定変更や、開発者の感想など。
